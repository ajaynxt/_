# AJAY NXT — Main Professional Portfolio v3.1.0

This is the **main ajaynxt.com portfolio**, rebuilt as a new premium personal studio website from the user's uploaded source. It is not a demo-only website.

## Professional direction

- Ajay Saini and AJAY NXT are the primary story.
- Real client work appears before the capability/demo library.
- Hero uses Ajay's existing clean portrait with separate HTML text.
- Hero CTAs focus on selected work and starting a project, not on demos.
- Demo websites are lower on the page, clearly labelled, and connected to their live links.
- Additional website entries already stored in Firebase merge automatically into the public portfolio.
- Instagram, LinkedIn, Threads, Facebook, WhatsApp, email and optional YouTube/GitHub fields are supported.
- Seven curated palettes rotate smoothly every three minutes.
- Seven thin luxury heading fonts are selectable in the existing Firebase admin.
- Motion is lightweight CSS/vanilla JavaScript and respects reduced motion.
- Contact enquiries continue to save to Firestore with WhatsApp fallback.

## Deploy

Deploy this folder to the existing `ajaynxt.com` Firebase Hosting target. Keep the current `firebase-config.js`, rules, Firebase bundles, domain files, SEO files and admin folder.

## Validation performed

- JavaScript syntax checks for public scripts and admin script.
- HTML parser checks for public and admin pages.
- ZIP integrity and expected file structure checks.

A live browser render could not be completed in the execution environment because local browser navigation was blocked, so final visual QA should be done after preview/deploy on desktop and mobile.
