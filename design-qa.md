# Design and QA Notes

- Main portfolio, not a separate demo site.
- Client projects and demo concepts are visually and semantically separated.
- Portrait and text are separate layers.
- Hero motion uses CSS transforms and opacity only.
- Seven curated palettes rotate every 180 seconds minimum.
- Heading font remains fixed until changed in admin.
- Demo cards communicate style counts where known.
- Images are lazy-loaded below the hero and dimensions are reserved by CSS.
- Videos load only after a user selects a film.
- Forms use labels, input modes, focus states and inline status.
- `prefers-reduced-motion` is respected.
